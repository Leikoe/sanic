# reset()

*Instance Method · iOS 8.0, iPadOS 8.0, Mac Catalyst 13.1, macOS 10.11, tvOS, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlvertexdescriptor/reset()>

Resets the default state for the vertex descriptor.

## Declaration

```swift
func reset()
```

## Discussion

After reset, each element of the [attributes](https://developer.apple.com/documentation/metal/mtlvertexdescriptor/attributes) array has a default vertex attribute descriptor, and each element of the [layouts](https://developer.apple.com/documentation/metal/mtlvertexdescriptor/layouts) array has a default vertex buffer layout descriptor.
