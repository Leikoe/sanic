# device

*Instance Property · iOS 8.0, iPadOS 8.0, Mac Catalyst 13.1, macOS 10.11, tvOS, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlcommandencoder/device>

The Metal device from which the command encoder was created.

## Declaration

```swift
var device: any MTLDevice { get }
```

## Discussion

This command encoder can only be used with this [MTLDevice](https://developer.apple.com/documentation/metal/mtldevice).
