# MTLDataType.bfloat

*Case · iOS 17.0, iPadOS 17.0, Mac Catalyst 17.0, macOS 14.0, tvOS 17.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtldatatype/bfloat>

A 16-bit, brain floating-point value.

## Declaration

```swift
case bfloat
```

## Discussion

The 16-bit value stores one sign bit, eight exponent bits, and seven mantissa bits.
