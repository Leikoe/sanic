# init(rawValue:)

*Initializer · iOS 14.0, iPadOS 14.0, Mac Catalyst 14.0, macOS 11.0, tvOS 14.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlcommandbuffererroroption/init(rawvalue:)>

Creates a set of error options from a raw integer value.

## Declaration

```swift
init(rawValue: UInt)
```

## Parameters

- **rawValue** — The set of flags to use.

## Discussion

Use the [MTLCommandBufferErrorOption](https://developer.apple.com/documentation/metal/mtlcommandbuffererroroption) structure’s type properties, such as [encoderExecutionStatus](https://developer.apple.com/documentation/metal/mtlcommandbuffererroroption/encoderexecutionstatus), instead of this initializer.
