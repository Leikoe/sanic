<https://developer.apple.com/documentation/metal/mtl4argumenttable/label>

Assigns an optional label with this argument table for debugging purposes.

## Declaration

```swift
var label: String? { get }
```

## Discussion

You set this label by setting property [label](https://developer.apple.com/documentation/metal/mtl4argumenttabledescriptor/label) on the descriptor object, prior to creating this table instance.
