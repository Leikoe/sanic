# size

*Instance Property · iOS 12.0, iPadOS 12.0, Mac Catalyst 13.1, macOS 10.14, tvOS 12.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlindirectcommandbuffer/size>

The number of commands contained in the indirect command buffer.

## Declaration

```swift
var size: Int { get }
```

## Discussion

You set the value of this property when you create the indirect command buffer, and afterwards it doesn’t change.
