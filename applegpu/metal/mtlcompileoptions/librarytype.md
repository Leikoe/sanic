# libraryType

*Instance Property · iOS 14.0, iPadOS 14.0, Mac Catalyst 14.0, macOS 11.0, tvOS 14.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlcompileoptions/librarytype>

The kind of library to create.

## Declaration

```swift
var libraryType: MTLLibraryType { get set }
```

## Discussion

The default value is [MTLLibraryType.executable](https://developer.apple.com/documentation/metal/mtllibrarytype/executable).
