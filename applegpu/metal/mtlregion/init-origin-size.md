# init(origin:size:)

*Initializer · iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS*

<https://developer.apple.com/documentation/metal/mtlregion/init(origin:size:)>

Initializes a new region with the specified origin and size.

## Declaration

```swift
init(origin: MTLOrigin, size: MTLSize)
```

## Parameters

- **origin** — The origin of the region.
- **size** — The size of the region.
