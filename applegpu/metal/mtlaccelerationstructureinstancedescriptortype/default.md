# MTLAccelerationStructureInstanceDescriptorType.default

*Case · iOS 15.0, iPadOS 15.0, Mac Catalyst 15.0, macOS 12.0, tvOS 16.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlaccelerationstructureinstancedescriptortype/default>

An option specifying that the instance uses the default characteristics.

## Declaration

```swift
case `default`
```

## Discussion

This instance type corresponds to the [MTLAccelerationStructureInstanceDescriptor](https://developer.apple.com/documentation/metal/mtlaccelerationstructureinstancedescriptor)  structure memory layout.

- [MTLAccelerationStructureInstanceDescriptorType.indirect](https://developer.apple.com/documentation/metal/mtlaccelerationstructureinstancedescriptortype/indirect) — An option that enables an instance descriptor memory layout the GPU can populate.
