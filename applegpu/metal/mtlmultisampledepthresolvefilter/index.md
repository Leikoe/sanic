# MTLMultisampleDepthResolveFilter

*Enumeration · iOS 9.0, iPadOS 9.0, Mac Catalyst 13.1, macOS 10.14, tvOS 9.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlmultisampledepthresolvefilter>

Filtering options for controlling an MSAA depth resolve operation.

## Declaration

```swift
enum MTLMultisampleDepthResolveFilter
```

## Topics

### Depth resolve filters
- [MTLMultisampleDepthResolveFilter.sample0](https://developer.apple.com/documentation/metal/mtlmultisampledepthresolvefilter/sample0) — No filter is applied.
- [MTLMultisampleDepthResolveFilter.min](https://developer.apple.com/documentation/metal/mtlmultisampledepthresolvefilter/min) — The GPU compares all depth samples in the pixel and selects the sample with the smallest value.
- [MTLMultisampleDepthResolveFilter.max](https://developer.apple.com/documentation/metal/mtlmultisampledepthresolvefilter/max) — The GPU compares all depth samples in the pixel and selects the sample with the largest value.
