# MTLAttributeFormat.floatRGB9E5

*Case · iOS 17.0, iPadOS 17.0, Mac Catalyst 17.0, macOS 14.0, tvOS 17.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlattributeformat/floatrgb9e5>

One packed 32-bit value representing pixel data containing 9-bit float red, green, and blue channels, and a 5-bit float shared exponent channel.

## Declaration

```swift
case floatRGB9E5
```

## Discussion

This data format is identical to [MTLPixelFormat.rgb9e5Float](https://developer.apple.com/documentation/metal/mtlpixelformat/rgb9e5float), and used in compute functions for manipulating pixels.
