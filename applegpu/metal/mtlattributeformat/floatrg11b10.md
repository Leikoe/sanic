# MTLAttributeFormat.floatRG11B10

*Case · iOS 17.0, iPadOS 17.0, Mac Catalyst 17.0, macOS 14.0, tvOS 17.0, visionOS 1.0*

<https://developer.apple.com/documentation/metal/mtlattributeformat/floatrg11b10>

One packed 32-bit value representing pixel data containing 11-bit float red and green channels, and a 10-bit float blue channel.

## Declaration

```swift
case floatRG11B10
```

## Discussion

This data format is identical to [MTLPixelFormat.rg11b10Float](https://developer.apple.com/documentation/metal/mtlpixelformat/rg11b10float), and used in compute functions for manipulating pixels.
